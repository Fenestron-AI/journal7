# План раздела: Нормативная база

> Детальный план раздела «Нормативная база» (страницы: документы, AI-чат, настройки НПБ).
> Карта разделов — в `ROADMAP.md`, общие решения и статусы — в `PLAN.md` (Шаги 1–7).

---

## Цель раздела

База нормативно-правовых документов для НСБ (независимая сбытовая компания):
каталог документов с официальных источников, скачивание файлов, RAG-индексация
с распознаванием формул, AI-чат с цитированием норм. Профиль: население + ОРЭМ.

## Архитектура раздела

```
frontend: /ai/documents · /ai/chat · /ai/settings   (SPA, раздел = роуты)
     │ REST
Kotlin: modules/ai — тонкий прокси (AiRoutes → AiWorkerClient)
     │ http://localhost:8000 (→ AI_WORKER_URL из env, Шаг 7)
Контейнер journal7-worker (FastAPI):
     ├─ sync_llm: гибридный синк (детерминированный сбор ссылок + LLM-классификация)
     ├─ downloader: параллельное скачивание, оригинальные имена, retry
     ├─ ingestion: чанкинг + эмбеддинги (Yandex) + формулы (p2t, docx_math)
     ├─ qa: RAG-чат с цитированием, «агент не считает»
     ├─ scheduler: автосинк по расписанию (процесс, выключен по умолчанию)
     └─ p2t serve :8001 (OCR формул) + LibreOffice + poppler + модели
БД: ai.* схемы (documents, chunks, sources, catalog_rules, file_sources,
    sync_diffs, activity) в общей PostgreSQL (pgvector)
Файлы: data/legal-docs/<source>/ (bind-mount)
```

## Текущий цикл доработок (порядок)

1. **torch CPU-only** в Dockerfile CPU-ветки → размер образа 11.4GB → ~6.5GB
2. **AI_WORKER_URL в env** — убрать hardcode `localhost:8000` из AiWorkerClient
3. **Scheduler в контейнер** — 3-й процесс в entrypoint (ENABLE_SCHEDULER)
4. **Тесты воркера** — первый набор: docx_math (oMath→LaTeX), ingestion (чанки, формулы), sync_llm (правила), downloader (имена -2/-3)
5. **Операционный прогон**: синк 12 источников → скачивание 175 файлов → инжест → проверка чанков с формулами → тест AI-чата с цитированием
6. **UI-полировка** после пересборки фронта (отдельный проект, ROADMAP)

## Сценарии приёмочного тестирования

- Синк 12 источников → каталог пополняется; diff появляется; «Подтвердить» очищает бейдж
- Правило exclude (например, `%отчёт%`) убирает документы при синке; include возвращает
- Категория и интервал расписания применяются (пакетно в UI)
- Скачивание: оригинальные имена файлов, дубликаты `-2`, `-3`, ошибки → retry, pause/resume
- DOCX с oMath и WMF-формулой → в чанке `$$...$$` на своих местах
- PDF ПП 442 → формулы LaTeX в чанках (55 формул из пилота)
- Чат: «Как рассчитывается сбытовая надбавка?» → ответ с цитатой «п. X документа Y» и формулой
- Забыть / Восстановить / Сменить категорию (пакетно) — состояние сохраняется через ресинк
- Формулы: агент цитирует, не пересчитывает («ты не калькулятор»)
